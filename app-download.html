选择你的安装方式

本站是可安装的 Web 应用（PWA），安装过程由浏览器完成，几步就能把图标放到桌面上。

Android 推荐

Chrome、Edge 等 Chromium 浏览器

  1. 用浏览器打开本站（需 HTTPS）。
  2. 点右上角菜单，选择「安装应用」或「添加到主屏幕」。
  3. 确认后即可从桌面图标以独立窗口启动。

安装包由浏览器生成，无需下载 APK，也不经过应用商店。

iPhone / iPad

Safari 浏览器

  1. 用 Safari 打开本站。
  2. 点底部「分享」按钮，向下找到「添加到主屏幕」。
  3. 命名并确认，图标会出现在主屏幕上。

iOS 目前只允许通过 Safari 添加到主屏幕。

桌面浏览器

Chrome、Edge（Windows / macOS / Linux）

  1. 在地址栏右侧找到安装图标。
  2. 或从浏览器菜单选择「安装」，把站点装成独立应用。
  3. 安装后可固定到任务栏或程序坞。

与浏览器共享登录状态，数据实时同步。

常见问题

关于安装、更新、离线与数据安全，这里给出直接的回答。

安装需要经过应用商店吗？

不需要。本站是可安装的 Web 应用（PWA），由浏览器直接安装到主屏幕或桌面，不提供 APK，也没有上架 Google Play 或 App Store。

Android 上怎么安装？

用 Chrome 或 Edge 打开本站，点右上角菜单里的「安装应用」或「添加到主屏幕」即可。站点需要运行在 HTTPS 下，浏览器才会开放安装入口。

iPhone / iPad 上怎么安装？

用 Safari 打开本站，点底部「分享」，选择「添加到主屏幕」。iOS 目前只支持通过 Safari 完成这一步。

安装后怎么更新？

无需手动更新。页面资源带有内容哈希，Service Worker 在后台拉取新版本并在下次进入时生效，你不需要回到应用商店重新下载。

断网还能用吗？

已缓存的界面资源可以打开，导航请求失败时会回退到离线页并给出提示；发布内容、私信等需要联网的操作会在恢复连接后继续。

会收到系统推送通知吗？

目前使用站内的实时提醒与未读角标，不申请系统级推送权限，因此不会在系统通知栏打扰你。

安装版和浏览器里访问有什么区别？

数据完全一致，共用同一个账号与登录状态。安装版以独立窗口运行、有独立图标、不显示浏览器地址栏，离线体验也更好。
